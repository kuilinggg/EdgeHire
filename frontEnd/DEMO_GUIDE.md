# EdgeHire HR模块演示指南

## 🎯 功能概览

EdgeHire HR模块提供了完整的简历浏览和求职指导功能，界面美观，交互流畅，完全符合现代Web应用的设计标准。

## 🚀 快速开始

### 启动项目
```bash
cd frontEnd
npm run dev
```

访问：http://localhost:5174/

### 登录信息
- 用户类型：HR
- 导航到HR模块进行体验

## 📋 功能演示路径

### 1. 简历浏览功能 (`/hr/resume-list`)

#### 🔍 搜索和筛选
- **关键词搜索**：输入"前端"、"Vue"、"JavaScript"等关键词
- **高级筛选**：
  - 工作经验：应届毕业生、1-3年、3-5年等
  - 学历要求：高中、大专、本科、硕士、博士
  - 行业领域：互联网/IT、金融、教育等
  - 期望城市：北京、上海、广州、深圳等

#### 📄 简历卡片交互
- **悬停效果**：鼠标悬停查看卡片动画
- **收藏功能**：点击星形图标收藏/取消收藏
- **查看详情**：点击"查看详情"按钮打开详情弹窗

#### 📊 简历详情弹窗
- **完整信息展示**：基本信息、求职意向、工作经历等
- **操作按钮**：
  - "发起沟通"：跳转到私聊页面
  - "提出修改建议"：跳转到指导页面

### 2. 求职指导功能 (`/hr/guidance`)

#### 📑 标签页切换
- **待处理**：显示新的指导请求
- **指导中**：显示正在进行的指导
- **已完成**：显示历史指导记录

#### 🔍 搜索功能
- 支持按求职者姓名、职位、指导类型搜索

#### 📋 请求处理流程
1. **查看请求**：点击"查看并处理"按钮
2. **详情展示**：
   - 左侧：求职者完整信息和指导需求
   - 右侧：处理操作区域
3. **处理决策**：
   - **接受指导**：开始提供指导服务
   - **婉拒请求**：选择拒绝原因
4. **完成指导**：为处理中的请求添加完成备注

## 🎯 用户场景

### HR日常工作流
1. **浏览推荐简历** → 查看匹配度高的候选人
2. **搜索特定人才** → 根据职位需求精准搜索
3. **查看简历详情** → 全面了解候选人信息
4. **发起沟通** → 与心仪候选人建立联系
5. **处理指导请求** → 提供专业的求职建议

### 指导服务流程
1. **接收请求** → 查看求职者的指导需求
2. **评估决策** → 根据专业领域决定是否接受
3. **提供指导** → 与求职者沟通，给出建议
4. **完成服务** → 结束指导，等待平台结算
