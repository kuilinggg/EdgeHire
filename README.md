# EdgeHire

#### 后端配置
在application.yml.template同级文件夹下新建application.yml，把前者的内容复制进去，并且输入你自己的数据库密码

#### AI配置
同上，输入你自己的api秘钥

#### 介绍
软工实训项目

#### 项目基础功能：

- 1.用户能够填写和发布简历； 
- 2.用户能够提交求职信息； 
- 3.HR 能够浏览和对简历提出修改意见； 
- 4.HR 能够浏览求职信息和联系面试； 
- 5.后台管理：管理用户和HR信息，并对求职信息进行审查； 
- 6.统计分析：后台管理有一些统计分析图表。 

#### 项目拓展功能：
- 1.利用AI大模型生成用户专属简历； 
- 2.设计实现求职信息和HR相匹配的算法； 
- 3.设计实现求职信息关联推荐算法； 
- 4.实现会员制功能。
